# Figma backups

Archive copies of the Figma file (`.fig`). These are backups only. Never edit a downloaded copy and re-upload it; the live file in Figma is the source of truth.

**To make one (lead, weekly or before a big change):** in Figma, **File → Save local copy…**, name it `tourix-YYYY-MM-DD.fig`, put it in this folder, commit and push.

GitHub rejects files over 100 MB. If a backup is bigger, use Git LFS (`git lfs track "*.fig"`) or keep it in a shared drive and link it here.
